# cleanup sweep: dead code and known warts

Parking list for small tidy-ups near the mermaid/render path. No hard
dependencies; none of these are urgent.

## Dead `svg64` base64 block

`internal/transformers/mermaid.go:70-78` base64-encodes the rendered SVG
into `svg64`, which is never used — the image `src` is the SVG filename, not
a data URI. Delete the block.

## SVG naming: content hash instead of `randHex`

SVG files are named with a random 64-hex string (`randHex(32)`), so two
renders of the same diagram produce different filenames. Replace with
content-derived naming (e.g. hash of the diagram source), so repeated
renders are diff-stable.

## `render()` malformed HTML

`cmd/mdsick/root.go` `render()` writes `</body></html>` before the markdown
body and again after it. Browsers recover; every rendered file (stdin and
batch mode) is technically malformed. Fix the shell structure and visually
re-verify the result in the browser — do not assume it renders identically.
