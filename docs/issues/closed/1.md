# Program hangs on "mermaiding..." when input contains no mermaid diagrams

When piping markdown without any mermaid code blocks, the program gets stuck displaying the `mermaiding...` progress bar and never completes.

### Reproduction

```sh
echo hi | mdsick
```

### Expected behavior

The program should complete immediately, producing output with no progress bar (since there is nothing to render).

### Actual behavior

The `mermaiding...` progress bar is displayed and the program hangs indefinitely.
